# Telegram Data Entry Bot 🤖

This is a Telegram bot built using Python that collects user information and stores it in a text file.

## ✅ Features

- Collects user data:
  - Name
  - Age
  - Gender
  - Marital Status
- Uses buttons for better user interaction
- Saves data into `user_data.txt`
- Command to view saved data

## ✅ Commands

/start  → Start data entry  
/show   → Show all saved data  

## ✅ Technologies Used

- Python
- python-telegram-bot
- Flask (for deployment)

## ✅ How It Works

1. User sends `/start`
2. Bot asks questions step by step
3. Data is collected and saved in a text file
4. User can see all data using `/show`
